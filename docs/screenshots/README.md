# Screenshots

Drop your own images in this folder using the **same filenames**. The main README picks them up automatically.

| File | What to capture |
| --- | --- |
| `hero.png` | The top of the live site on a desktop screen |
| `verdict.png` | After pressing "Stamp it!": the verdict stamp, buddy and score |
| `case-file.png` | The left column after a verdict: breakdown bars, questions, next move |
| `field-guide.png` | The "Field guide" section |
| `share-card.png` | The PNG you get from "Make share card" then "Save image" |
| `mobile.png` | A phone screenshot of the site |
| `demo.gif` | A 5 to 10 second screen recording: paste, stamp, verdict |

## Tips

- Capture from the live site (https://scam-hai-kya.vercel.app/) so the real fonts show up.
- **Full-page desktop shot in Chrome:** DevTools (F12) > Ctrl/Cmd+Shift+P > "Capture full size screenshot".
- **Verdict shot:** click the "The Fee Trap" ticket, wait 3 seconds for the stamp to land, then screenshot.
- **GIF:** record with ScreenToGif (Windows), Kap (macOS) or Peek (Linux). Keep it under about 5 MB.
- **Upload without Git:** on GitHub open this folder, then Add file > Upload files, and drop them in. Same filename overwrites the placeholder.
